# 潮游旅行社交APP - 数据库设计文档

## 📋 概述

本项目为潮游旅行社交APP的完整数据库设计，包含用户管理、活动发布、圈子社交、消息系统、个人中心等核心功能模块的数据表结构。

## 🗂️ 文件结构

```
sql/
├── 01_base_tables.sql       # 基础数据表（用户、地区、配置等）
├── 02_activity_tables.sql   # 活动模块数据表
├── 03_circle_tables.sql     # 圈子社交模块数据表
├── 04_message_tables.sql    # 消息系统数据表
├── 05_profile_tables.sql    # 个人中心模块数据表
├── 06_admin_tables.sql      # 管理后台数据表
├── 07_init_data.sql         # 初始化数据脚本
└── README.md               # 说明文档
```

## 🚀 快速开始

### 1. 创建数据库

```sql
CREATE DATABASE chaoyou CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE chaoyou;
```

### 2. 执行SQL脚本

按以下顺序执行SQL脚本：

```bash
# 1. 基础数据表
mysql -u root -p chaoyou < 01_base_tables.sql

# 2. 活动模块表
mysql -u root -p chaoyou < 02_activity_tables.sql

# 3. 圈子社交模块表
mysql -u root -p chaoyou < 03_circle_tables.sql

# 4. 消息系统表
mysql -u root -p chaoyou < 04_message_tables.sql

# 5. 个人中心模块表
mysql -u root -p chaoyou < 05_profile_tables.sql

# 6. 管理后台表
mysql -u root -p chaoyou < 06_admin_tables.sql

# 7. 初始化数据（可选）
mysql -u root -p chaoyou < 07_init_data.sql
```

### 3. 一键执行所有脚本

```bash
# Linux/Mac
cat *.sql | mysql -u root -p chaoyou

# Windows
type *.sql | mysql -u root -p chaoyou
```

## 🔧 技术特性

### 数据库特性
- **字符集**: UTF8MB4，支持emoji和特殊字符
- **存储引擎**: InnoDB，支持事务和外键约束
- **索引优化**: 为常用查询字段创建索引
- **JSON支持**: 使用JSON字段存储复杂数据结构

### 设计亮点
- **软删除**: 重要数据采用软删除机制
- **审计字段**: 创建时间、更新时间、创建人、更新人
- **状态管理**: 统一的状态字段设计
- **计数冗余**: 关键统计数据冗余存储，提升查询性能
- **分层设计**: 清晰的模块化设计，便于维护

## 📈 性能优化

### 索引策略
- **主键索引**: 所有表都有自增主键
- **唯一索引**: 用户名、手机号、邮箱等唯一字段
- **复合索引**: 多字段查询的复合索引
- **时间索引**: 创建时间、更新时间索引

### 查询优化
- **分页查询**: 支持高效的分页查询
- **计数缓存**: 点赞数、评论数等统计字段
- **状态过滤**: 为状态字段创建索引
- **软删除索引**: is_deleted字段索引

## 🔒 数据安全

## 📝 开发建议

### 命名规范
- **表名**: tb_前缀 + 模块名 + 功能名
- **字段名**: 下划线命名法
- **索引名**: idx_前缀 + 字段名
- **唯一约束**: uk_前缀 + 字段名

### 开发注意事项
1. 所有时间字段使用datetime类型
2. 金额字段使用decimal(10,2)
3. 状态字段统一使用tinyint
4. JSON字段用于存储灵活的扩展数据
5. 重要操作记录操作日志
